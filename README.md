# Luminus Proposal System

A modern, AI-integrated proposal generation system.

## 📚 Documentation
**Please read the [USER_GUIDE.md](./USER_GUIDE.md) for full setup instructions.**

The User Guide covers:
- **Local Setup**: How to run `npm run dev`.
- **Environment Variables**: What to put in `.env`.
- **Supabase**: Start-to-finish database setup.
- **N8N Workflows**: How to configure email automation.
- **Vercel Deployment**: How to deploy freely to the cloud.

## Quick Start
1.  Install dependencies:
    ```bash
    npm install
    ```
2.  Run development server:
    ```bash
    npm run dev
    ```

## Features
- AI Image Generation (Replicate/Imagine.art)
- Professional PDF Generation
- Multi-Company Layout Support
- Automated Email Sending via N8N
- Google Sheets Integration for Lead Tracking
